# Zadania: Visual Studio Code

Tym razem zajmiemy się zadaniami związanymi z użyciem lokalnej instalacji Visual Studio Code na komputerze pracowni a nie poprzez Code Spaces na sforkowane repozytorium na stronie GitHub..

## Zadanie 1.

1. Połącz się poprzez `Open an Remote Window` w Visual Studio Code ze swoim sforkowanym repozytorium.

Jeśli jesteś zaawansowanym użytkownikiem, możesz zamiast tego sklonować repozytorium lokalnie i połączyć je z VS Code.

## Zadanie 2.

W VS Code użyj Explorera by wejść do folderu `pages/zadania/04_sol_vscode`.

## Zadanie 3.

Utwórz tam kompleksowy `raport.md` który ma zawierać opis rzutu ukośnego bez i z oporem powietrza.

1. Oczekuję sekcji, tekstu, równań matematycznych, ich wyprowadzeń.

2. Oczekuje się wielu wykresów ilustrujących ruch ciała w rzucie ukośnym wraz z załączonymi obrazkami i prezentowanym kodem). Pamiętaj, że nie jesteś w Colabie i by stworzyć wykresy musisz jakoś uruchomić kod Pythona (np. w pomocniczym Colabie, lub poprzez uruchomienie pyhonowego pliku w samym VS Code).

3. Uwaga: 
    a. raport.md ma przypominać przykład z example/raport.md. 
    b. Masz użyć wartość prędkości początkowej v0 = dwie pierwsze cyfry twojego indeksu. 
    c. Masz użyć kąt początkowy α = dwie ostatnie cyfry twojego indeksu.
    d. Wszystkie wartości powinny być zapisane w jednostkach SI.
    
Raport ma mieć strukturę:

~~~markdown
# Raport

## Cel

## Metoda

## Kod

## Wyniki

## Wniosek
~~~

## Zadanie 4.

1. Po zakończonej pracy prześlij zmiany do swojego repozytorium używając Source Control w Visual Studio Code lub poprzez terminal (komenda `git push`).

2. Upewnij się, przez przeglądarkę internetową czy na stronie GitHub w Twoim repozytorium widoczne są wprowadzone zmiany i raport poprawnie się wyświetla!
